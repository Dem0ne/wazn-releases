# WAZN | وَزْن — releases

هذا المستودع للإصدارات فقط: مثبت «وَزْن» لـWindows وملف التحديث الموقّع `wazn-update.json`. الكود المصدري خاص وليس هنا.

- **التحميل:** من صفحة [Releases](https://github.com/Dem0ne/wazn-releases/releases) نزّل `Wazn-Setup-<الإصدار>.exe`.
- **التحديث التلقائي:** البرنامج يقرأ `releases/latest/download/wazn-update.json`. كل ملف موقّع بمفتاح BitSync الخاص. البرنامج يرفض أي ملف أو مثبت لا يطابق التوقيع والحجم والبصمة.
- **العائلة:** «وَزْن» من BitSync. لا علاقة رسمية له بـGameSir.

This repository holds WAZN's Windows installers and signed update manifests only; the source code is private.
